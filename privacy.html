Privacy policy

Last updated: 11 October 2026

Who is responsible

MiBudget is a private, non-commercial project operated by Cristian Moroaica, who is its only user. Contact: cristian@mimirslab.com.

What data is processed

With the operator's own consent, MiBudget retrieves account details, balances and transactions of the operator's own bank account (ING Bank Romania) through the account information (AIS) interface of Enable Banking, a licensed account information service provider. Access is read-only. No payments are initiated.

Where it is stored

Retrieved data and credentials are stored locally on the operator's own computer. They are not sold, shared with third parties, used for advertising or analytics, or uploaded to any server operated for MiBudget.

This website

This site is static and consists of three informational pages. It sets no cookies and contains no analytics or trackers. It is hosted on GitHub Pages, which may keep ordinary server logs under its own privacy statement.

Sign-in callback

After you approve access in your bank's app, the bank sends your browser to mibudget.mimirslab.com/callback. That page only contains a script that forwards the one-time result to localhost on your own computer. It does not store, log or transmit it elsewhere, but because the page is served by GitHub Pages, the request address may appear in GitHub's own server logs. The one-time code is useless without the private key, which stays on the operator's computer.

Consent and retention

Bank access is granted by the operator in the bank's own authentication flow and can be withdrawn at any time in the bank's app or by deleting the local data. Local data is kept for as long as the operator uses the tool.

Your rights

Because only the operator's own data is processed, no third-party personal data is collected. For any question about this policy, write to the contact address above.
